# Deventure Front · Entrega 1 · Plan de implementación

> **Para agentes:** SUB-SKILL REQUERIDA: usar superpowers:subagent-driven-development (recomendado)
> o superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan checkbox
> (`- [ ]`) para seguir el avance.

**Objetivo:** construir la base del frontend de Deventure y el recorrido inicio → registro/login →
intro con Björn → zonas, conectado al backend real, con estética vikinga y animaciones.

**Arquitectura:** SPA con Vite + React 19 + TypeScript, organizada por feature (`src/features/*`)
sobre una capa compartida (`src/shared/*`) y stores de Zustand. Los datos del servidor pasan por un
único `httpClient` que valida con Zod y los cachea TanStack Query. Las animaciones usan Motion con
`MotionConfig reducedMotion="user"`.

**Stack:** pnpm 10, Vite, React 19, TypeScript estricto, Tailwind CSS v4, React Router 7, TanStack
Query 5, Zustand 5, react-hook-form 7 + Zod 3.25, Motion 12, lucide-react, @fontsource.

**Spec:** `docs/specs/2026-10-13-entrega-1-design.md`

## Restricciones globales

- Node 22 (`.nvmrc`), pnpm 10 (`packageManager` en `package.json`).
- Front en el puerto **5173** (`strictPort`); backend por el gateway en `VITE_API_URL`
  (`http://localhost:3000` en desarrollo).
- TypeScript con `strict` y `noUncheckedIndexedAccess`. Prohibido `any`.
- Sin comentarios ni JSDoc en el código. Sin `console`. Nombres de 2 caracteres o más.
- Sin funciones inline en props de JSX: los handlers se declaran en el cuerpo del componente.
- Sin comparar contra `null`/`undefined`; usar truthiness, `??`, `?.` u `Object.hasOwn`.
- Sin ternarios anidados. Sin `catch {}` vacío.
- Ningún color hex en componentes: solo tokens de `src/styles/theme.css`.
- Imports con alias `@/`; prohibido `../`.
- Una feature no importa de otra feature.
- Solo se animan `transform` y `opacity`.
- Textos de interfaz en español rioplatense ("vos") y en `src/shared/constants/copy.ts`.
- Tests automatizados **no obligatorios** (decisión del equipo): cada tarea se verifica con
  `pnpm typecheck`, `pnpm lint`, `pnpm build` y pasos manuales con Playwright.
- **Commits:** cada tarea termina proponiendo el commit; el usuario lo ejecuta o lo autoriza.

## Foco de revisión

1. **Backend caído o sin red al loguearse:** mensaje genérico ("La niebla cubrió el camino"), el
   botón se vuelve a habilitar y no se rompe la pantalla. Verificado en la Tarea 9.
2. **Token vencido o inválido en `localStorage` al abrir la app:** `GET /api/auth/me` responde 401,
   la sesión se limpia sola y "Jugar" lleva a `/login`, sin bucles de redirección. Verificado en la
   Tarea 7.
3. **"Reducir movimiento" activado:** todo se puede usar, el texto de Björn aparece completo al
   instante y no quedan animaciones infinitas de desplazamiento. Verificado en las Tareas 10 y 12.
4. **Ninguna zona publicada (`data: []`):** mensaje de estado vacío, nunca una pantalla en blanco.
   Verificado en la Tarea 11.
5. **Doble clic o envío repetido** (login, registro, "Saltar intro"): un solo pedido, botón
   deshabilitado mientras está pendiente. Verificado en las Tareas 9 y 10.

## Desvíos respecto de la spec (decididos al planificar)

- `features/settings` pasa a `src/shared/settings/`: lo usan inicio y zonas, y una feature no puede
  importar de otra. Lo mismo con el modal de salir (`src/shared/session/`).
- `Stars`, `Lives`, `ProgressBar` y la ilustración `ZoneIsland` no se crean en esta entrega: ninguna
  pantalla los usa (YAGNI). Llegan con el nivel jugable.
- La CSP estricta se configura en el deploy (DEV-37) como header del servidor: en desarrollo rompe
  el HMR de Vite.

```ts
export const NETWORK_ERROR_STATUS = 0;
export const UNAUTHORIZED_STATUS = 401;
export const SERVER_ERROR_MIN_STATUS = 500;

type ApiErrorInit = {
  status: number;
  code: string;
  message: string;
  details?: unknown;
};

export class ApiError extends Error {
  readonly status: number;
  readonly code: string;
  readonly details: unknown;

  constructor({ status, code, message, details }: ApiErrorInit) {
    super(message);
    this.name = 'ApiError';
    this.status = status;
    this.code = code;
    this.details = details;
  }
}

export function isRetryableError(error: unknown): boolean {
  if (!(error instanceof ApiError)) return true;
  return error.status === NETWORK_ERROR_STATUS || error.status >= SERVER_ERROR_MIN_STATUS;
}
```

```ts
import type { z } from 'zod';
import { ApiError, NETWORK_ERROR_STATUS, UNAUTHORIZED_STATUS } from '@/shared/api/ApiError';
import { env } from '@/shared/config/env';
import { COPY } from '@/shared/constants/copy';
import { errorResponseSchema } from '@/shared/contracts/common';
import { useSessionStore } from '@/stores/sessionStore';

type HttpMethod = 'GET' | 'POST' | 'PATCH' | 'DELETE';

type RequestOptions<TSchema extends z.ZodTypeAny> = {
  method?: HttpMethod;
  body?: unknown;
  responseSchema: TSchema;
};

const NETWORK_ERROR_CODE = 'NETWORK_ERROR';
const JSON_CONTENT_TYPE = 'application/json';
const EMPTY_BODY = {};
const UNKNOWN_ERROR_BODY = { error: { code: 'UNKNOWN_ERROR', message: COPY.errors.generic } };

async function readJsonBody(response: Response): Promise<unknown> {
  const contentType = response.headers.get('content-type') ?? '';
  if (!contentType.includes(JSON_CONTENT_TYPE)) return EMPTY_BODY;
  const body: unknown = await response.json();
  return body;
}

function buildRequestInit<TSchema extends z.ZodTypeAny>(
  options: RequestOptions<TSchema>,
  token: string | null,
): RequestInit {
  const headers = new Headers({ Accept: JSON_CONTENT_TYPE });
  if (token) headers.set('Authorization', `Bearer ${token}`);

  const requestInit: RequestInit = { method: options.method ?? 'GET', headers };
  if (Object.hasOwn(options, 'body')) {
    headers.set('Content-Type', JSON_CONTENT_TYPE);
    requestInit.body = JSON.stringify(options.body);
  }
  return requestInit;
}

async function sendRequest(url: string, requestInit: RequestInit): Promise<Response> {
  try {
    return await fetch(url, requestInit);
  } catch (networkError) {
    throw new ApiError({
      status: NETWORK_ERROR_STATUS,
      code: NETWORK_ERROR_CODE,
      message: COPY.errors.generic,
      details: networkError,
    });
  }
}

export async function requestApi<TSchema extends z.ZodTypeAny>(
  path: string,
  options: RequestOptions<TSchema>,
): Promise<z.output<TSchema>> {
  const { token, endSession } = useSessionStore.getState();
  const response = await sendRequest(
    `${env.VITE_API_URL}${path}`,
    buildRequestInit(options, token),
  );
  const responseBody = await readJsonBody(response);

  if (!response.ok) {
    if (response.status === UNAUTHORIZED_STATUS && token) endSession();
    const { error } = errorResponseSchema.catch(UNKNOWN_ERROR_BODY).parse(responseBody);
    throw new ApiError({ status: response.status, ...error });
  }

  return options.responseSchema.parse(responseBody);
}
```

```ts
import { LIMITS } from '@/shared/constants/limits';
import { useSettingsStore } from '@/stores/settingsStore';

type ToneOptions = {
  waveform: OscillatorType;
  frequencyStart: number;
  frequencyEnd: number;
  durationSeconds: number;
  peakGain: number;
  delaySeconds?: number;
};

const SILENT_GAIN = 0.001;
let audioContext: AudioContext | null = null;

function getAudioContext(): AudioContext {
  audioContext ??= new AudioContext();
  if (audioContext.state === 'suspended') void audioContext.resume();
  return audioContext;
}

function getVolumeFactor(): number {
  const { effectsVolume, isEffectsMuted } = useSettingsStore.getState();
  if (isEffectsMuted) return 0;
  return effectsVolume / LIMITS.volumeMax;
}

function playTone(options: ToneOptions): void {
  const volumeFactor = getVolumeFactor();
  if (!volumeFactor) return;

  const context = getAudioContext();
  const startTime = context.currentTime + (options.delaySeconds ?? 0);
  const endTime = startTime + options.durationSeconds;
  const oscillator = context.createOscillator();
  const gainNode = context.createGain();

  oscillator.type = options.waveform;
  oscillator.frequency.setValueAtTime(options.frequencyStart, startTime);
  oscillator.frequency.exponentialRampToValueAtTime(options.frequencyEnd, endTime);
  gainNode.gain.setValueAtTime(options.peakGain * volumeFactor, startTime);
  gainNode.gain.exponentialRampToValueAtTime(SILENT_GAIN, endTime);

  oscillator.connect(gainNode);
  gainNode.connect(context.destination);
  oscillator.start(startTime);
  oscillator.stop(endTime);
}

export function playRuneClick(): void {
  playTone({
    waveform: 'sine',
    frequencyStart: 640,
    frequencyEnd: 1080,
    durationSeconds: 0.08,
    peakGain: 0.12,
  });
}
```

```tsx
  const dialogRef = useRef<HTMLDialogElement>(null);

      ref={dialogRef}
```

```tsx
import { useQuery } from '@tanstack/react-query';
import { useEffect } from 'react';
import { fetchCurrentUser } from '@/shared/api/accountApi';
import { queryKeys } from '@/shared/api/queryKeys';
import { useSessionStore } from '@/stores/sessionStore';

export function SessionBootstrap() {
  const hasSession = useSessionStore((state) => Boolean(state.token));
  const updateUser = useSessionStore((state) => state.updateUser);

  const { data: currentUser } = useQuery({
    queryKey: queryKeys.account.me,
    queryFn: fetchCurrentUser,
    enabled: hasSession,
  });

  useEffect(() => {
    if (currentUser) updateUser(currentUser);
  }, [currentUser, updateUser]);

  return null;
}
```

```ts
import { ApiError, isRetryableError } from '@/shared/api/ApiError';
import { COPY } from '@/shared/constants/copy';
import { fieldErrorsSchema } from '@/shared/contracts/common';

const VALIDATION_ERROR_CODE = 'VALIDATION_ERROR';
const FIELD_BY_ERROR_CODE = new Map([
  ['USERNAME_TAKEN', 'username'],
  ['EMAIL_TAKEN', 'email'],
]);
const FORM_LEVEL_CODES = new Set(['INVALID_CREDENTIALS', 'ACCOUNT_LOCKED', 'TOO_MANY_REQUESTS']);

export function getFieldErrorMessage(error: unknown, fieldName: string): string | undefined {
  if (!(error instanceof ApiError)) return undefined;
  if (FIELD_BY_ERROR_CODE.get(error.code) === fieldName) return error.message;
  if (error.code !== VALIDATION_ERROR_CODE) return undefined;
  const fieldErrors = fieldErrorsSchema.catch({}).parse(error.details);
  return fieldErrors[fieldName]?.[0];
}

export function getFormErrorMessage(error: unknown): string | undefined {
  if (!error) return undefined;
  if (isRetryableError(error)) return COPY.errors.generic;
  if (error instanceof ApiError && FORM_LEVEL_CODES.has(error.code)) return error.message;
  return undefined;
}
```

El estado inicial depende de "reducir movimiento"; la página monta un `SpeechBubble` nuevo por

```ts
import { useReducedMotion } from 'motion/react';
import { useCallback, useEffect, useState } from 'react';
import { LIMITS } from '@/shared/constants/limits';

type Typewriter = { visibleText: string; isComplete: boolean; revealAll: () => void };

export function useTypewriter(fullText: string): Typewriter {
  const prefersReducedMotion = Boolean(useReducedMotion());
  const [visibleLength, setVisibleLength] = useState(prefersReducedMotion ? fullText.length : 0);
  const isComplete = visibleLength >= fullText.length;

  useEffect(() => {
    if (isComplete) return;
    const timeoutId = window.setTimeout(() => {
      setVisibleLength((currentLength) => currentLength + 1);
    }, LIMITS.typewriterCharacterDelayMs);
    return () => {
      window.clearTimeout(timeoutId);
    };
  }, [visibleLength, isComplete]);

  const revealAll = useCallback(() => {
    setVisibleLength(fullText.length);
  }, [fullText.length]);

  return { visibleText: fullText.slice(0, visibleLength), isComplete, revealAll };
}
```

```tsx
import { useState } from 'react';
import { LevelPreviewModal } from '@/features/zones/components/LevelPreviewModal';
```
